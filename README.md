# South Fade Barbers (v2)

Website for South Fade Barbershop, 5 Cavendish Parade, London SW4 9DW. Live at https://sadikmohamud.github.io/south-fade-barbers/ (the south-fade.com domain has lapsed; to restore it, renew the domain and add a CNAME file containing south-fade.com).

## What's in v2
- Hero with a hexagon light ceiling, inspired by the shop's own hex LED lights, that glows under the cursor
- Marquee service bands that speed up as you scroll
- Shopfront photo that opens out of a hexagon as you scroll, with the About story
- Live counters, an expanding price list with a floating photo on hover, kids corner and the shop interior
- Liquid glass navigation, a floating Book now button on phones, today's opening hours highlighted
- Booksy booking links throughout, Google Analytics kept, barbershop schema for Google

## Editing
- **Prices:** `assets/js/services.js`
- **Photos:** `assets/img/`
- **Logo:** `assets/img/logo.svg` (vector)

Static site, no build step, hosted on GitHub Pages (see `CNAME`).
